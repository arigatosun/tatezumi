## 進め方

1. Local のサイトを起動し、`http://sobakokoro.local/wp-admin/` にログインする
2. 下の「撮影する画面」を順に撮り、`docs/manual/screenshots/` に指定のファイル名で保存
3. `docs/manual/manual.html` を作る（下の構成）
4. HTML を PDF に変換して `docs/管理画面マニュアル.pdf` として出力

## マニュアルの構成

店主が読む前提。専門用語を避け、1手順につき1操作で書く。

1. ログインする
2. 管理画面の見方（どこに何があるか）
3. **お品書きの価格を変える** ← 最も頻度が高い
4. お品書きに品を追加する
5. 写真を入れ替える
6. 並び順を変える
7. **営業時間・定休日・電話を変える**（店舗情報）
8. お知らせを出す・消す
9. 困ったとき（間違えて消した／画像が出ない／変更が反映されない）

## 注意点

- **「店舗情報」を直すと全ページに反映される**ことを明記する（強み）
- 写真を入れると自動でカード表示に切り替わる仕組みを説明する
- 価格は「1,650円」のように表示したい文字をそのまま入れる（数値ではない）
- 公開後は `noindex` を外す必要があるが、これは制作側の作業なのでマニュアルには書かない
