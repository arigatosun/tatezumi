## ⚠️ 写真について（最重要）

現在の写真は**一軒家の老舗蕎麦屋**（古民家・のれん・座敷・蕎麦畑）の世界観で生成したもの。
実際は**商業施設（日生中央サピエ）1階のテナント**で、通し営業・予約不可・カード可という業態のため、
**実物とかなり印象が違う**。実店舗の撮影に差し替えるか、商業施設向けの明るい設定で生成し直す必要がある。
特に `exterior.jpg`（古民家の外観）と `interior.jpg`（座敷）は、キャプションが「お店の入口」「店内の様子」なので
実物と食い違ったまま公開するとまずい。**先方から内観・外観写真をもらうまでは公開しない**。

なお 2026-09-01 の打合せでも、業態に合うのはB案という見立ての通り「B寄りで」との回答だった（→ D案に反映済み）。

## 構成

```
tatezumi/
├── index.html            比較用インデックス（知人に見せる入口）
├── assets/
│   ├── css/base.css      共通リセット＋スマホ固定CTA
│   └── img/              生成画像12枚（Web用にJPEG化済み・計約3MB）
├── pattern-a/            玄 — 格式・職人（参考：京都 有喜屋）
├── pattern-b/            明 — 明るい・実用（参考：手打ちそばおんたけ）
├── pattern-c/            静 — 余白・和モダン（参考：そばの実／いづるや）
└── pattern-d/            温 — B×C（2026-09-01 打合せ反映・本命）
```

`pattern-d/` でA/B/C案から変えた点：

- ベースフォントを 17px に（B案比 約+12%）、丸ゴシック（Zen Maru Gothic）＋生成り背景でとっつきやすさを出す
- トップに「営業時間・定休日・予約不可＋電話・お店の場所」を集約し、スクロールせずに用が足りる形に
- 写真を各ページ2〜3枚に削減（B案の半分程度）
- 石臼（`stone-mill.jpg`）と手打ち（`craftsman-hands.jpg`）を不使用、そば畑（`buckwheat-field.jpg`）は継続使用
- そば粉の産地・仕入先・米の銘柄の断定表記を削除（店主未確認のため）
- 素材差し替えが必要な箇所にHTMLコメントで `【素材待ち】` `【要確認】` を残してある

各パターンに `index.html`（トップ）／`menu.html`（お品書き）／`access.html`（アクセス・営業時間）／`style.css`。

## WordPress 化の方針（D案で確定・素材が揃い次第着手）

- 固定ページ3枚（トップ／お品書き／アクセス）＋「お知らせ」を投稿タイプで運用
- お品書きは ACF（または再利用ブロック）で「品名・価格・注記・タグ」を配列管理し、店主が価格だけ直せる形に
- 営業時間・電話・住所はテーマオプション1箇所で管理し、全ページに出力（更新漏れを構造的に防ぐ）
- 「本日の営業／臨時休業」はお知らせ投稿の最新1件をトップに自動表示
