現在の写真は**一軒家の老舗蕎麦屋**（古民家・のれん・座敷・蕎麦畑）の世界観で生成したもの。

## 構成

```

├── index.html            3案の比較用インデックス（知人に見せる入口）
├── assets/
│   ├── css/base.css      共通リセット＋スマホ固定CTA
│   └── img/              生成画像12枚（Web用にJPEG化済み・計約3MB）
├── pattern-a/            玄 — 格式・職人（参考：京都 有喜屋）
├── pattern-b/            明 — 明るい・実用（参考：手打ちそばおんたけ）
└── pattern-c/            静 — 余白・和モダン（参考：そばの実／いづるや）
```

各パターンに `index.html`（トップ）／`menu.html`（お品書き）／`access.html`（アクセス・営業時間）／`style.css`。

## 3案とも共通で実装した「参考サイトからの改良点」

1. 営業時間・電話を全ページ常時表示（参考サイトはフッター埋没が多かった）
2. 「売り切れ次第終了」をトップの目立つ位置に明記
3. PCでもグローバルナビを隠さない（ハンバーガーはスマホのみ）
4. お品書きは画像・PDFでなくHTMLテキスト＋税込価格
5. 全品掲載（「他にもございます」で終わらせない）
6. 電話は `tel:` でタップ発信、地図はGoogleマップ埋め込み＋経路リンク
7. スマホは画面下に「電話」「地図」を固定表示
8. 重いオープニング演出を入れない（LCP対策）

## 画像について

Higgsfield MCP 経由 Nano Banana Pro（2K）で生成 → ffmpeg で JPEG 化・リサイズ。実消費 24 credits。
**日本語文字は生成AIが必ず崩すため、暖簾・看板の文字は生成せず無地**にし、店名はCSSのテキストで載せている。

## WordPress 化の方針（案が決まってから）

- 固定ページ3枚（トップ／お品書き／アクセス）＋「お知らせ」を投稿タイプで運用
- お品書きは ACF（または再利用ブロック）で「品名・価格・注記・タグ」を配列管理し、店主が価格だけ直せる形に
- 営業時間・電話・住所はテーマオプション1箇所で管理し、全ページに出力（更新漏れを構造的に防ぐ）
- 「本日の営業／臨時休業」はお知らせ投稿の最新1件をトップに自動表示
