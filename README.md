## WordPress 化（2026-09-17 着手・`wp-theme/sobakokoro/`）

自作のクラシックテーマ。D案の静的HTMLをそのままテンプレート化したもの。

- 固定ページ2枚（お品書き `menu` ／アクセス `access`）＋トップは `front-page.php`。
  「お知らせ」は通常の投稿を使い、最新1件をトップに自動表示する
- **お品書きはカスタム投稿タイプ `menu_item`（1品1投稿）**。区分は `menu_cat` タクソノミー。
  価格・注記・タグは自前のメタボックスで入力する。
  当初 ACF を想定していたが、**繰り返しフィールドは ACF の有料版機能**のため、
  標準機能だけで済むこの形にした（追加コストなし）
- **写真のある品はカード、ない品は価格表**という出し分けは、アイキャッチの有無を見て自動で行う。
  店主が写真を足すだけで表示形式が切り替わる
- 営業時間・電話・住所は管理画面の「店舗情報」1箇所で管理し、全ページ＋地図の埋め込みに反映
- ロゴは `custom-logo` に対応済み。届いたら 外観 > カスタマイズ > サイト基本情報 から登録すれば、
  ヘッダーのテキストが自動で画像に切り替わる（**テンプレートの修正は不要**）
- `seed/seed.php` … 静的HTML版の33品と固定ページを流し込むスクリプト。
  `wp eval-file wp-content/themes/sobakokoro/seed/seed.php` で実行。何度実行しても重複しない
- 「よく出るお品」はトップから外した（2026-09-17・先方判断）。
  代わりにこだわりセクションの末尾に「お品書きを見る」を置いて導線を確保している
- 公開前に `functions.php` の `sobakokoro_noindex()` を外すこと（検索避けが入ったままになる）

### 2026-09-17 の調整（ヒーロー）

- **ヒーローを4枚のスライドに変更**（そば畑 → 外観 → 天ざる → 手繰った麺／4秒ごと・フェード1.4秒）。
  1枚の写真で店を伝えようとすると、**俯瞰の料理写真は必ず器が切れるか料理がアップになりすぎる**。
  他店（川上庵＝外観／更科堀井＝そば畑／本田屋＝手繰った麺）を調べたところ、
  **料理をトレー俯瞰で見せているサイトは1件もなかった**ため、構図の選択そのものを変えた
- **PC用（2.10:1）とスマホ用（0.70:1）を別々に用意**し、`<picture>` で出し分けている。
  スマホは枠が縦長になるため、横長画像のままだと**中央3割しか映らない**（切り落とし70%）。
  縦構図を用意して9%まで下げた。スマホ用の外観は縦位置の実写 `S__118013976.jpg` を使用
- `assets/js/hero-slider.js` … 1枚目だけ先に読み込み、**残り3枚は load 後**に取得（LCP対策）。
  スマホ用 `source` を先に有効化してから `img.src` を入れないと、横長版を二重に取りに行く。
  `prefers-reduced-motion` では切り替えを止める
- 「朝打ちの、自家製麺です。」は削除。ページの見出しが無くなるため、
  **`sr-only` の h1 に店名**を置いてある（画面には出ない）
- 生成画像（そば畑・麺）の**実消費は合計4 credits**。麺は最初「長さを強調」と指示して
  麺が伸びすぎたため、「一口分・伸ばしすぎない」と指定して作り直している
