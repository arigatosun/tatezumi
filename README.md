## ⚠️ 写真について

**D案は料理写真がすべて実物**（看板データより）。残る仮素材は内観・外観の2枚だけ。

A/B/C案の写真は**一軒家の老舗蕎麦屋**（古民家・のれん・座敷・蕎麦畑）の世界観で生成したもの。
実際は**商業施設（日生中央サピエ）1階のテナント**なので**実物とかなり印象が違う**。

D案でも `exterior.jpg`（古民家の外観）と `interior.jpg`（座敷）は残っており、キャプションが
「お店の入口（イメージ）」「店内の様子（イメージ）」なので**実物と食い違ったまま公開するとまずい**。
先方から内観・外観写真をもらうまでは、この2枚の扱いに注意する。

なお 2026-09-01 の打合せでも、業態に合うのはB案という見立ての通り「B寄りで」との回答だった（→ D案に反映済み）。

`pattern-d/` でA/B/C案から変えた点：

- **看板と同じ見た目**：若草色の市松＋金箔の背景、白フチの見出し、白帯に明朝の価格という組み方を踏襲
- **書体（2026-09-01 選定）**：見出し・店名・品名は **しっぽり明朝 B1 800**、本文とUIは M PLUS Rounded 1c。
  候補の比較ページを `pattern-d/font-samples.html` に残してある（丸ゴシック系・極太ゴシック系・筆書体の全8案）。
  看板の実物は写研/モリサワ系の極太丸ゴシック（新丸ゴ U 相当）だが、Webフォントとしては使えないため代替から選定
- ベースフォントを 17px に（B案比 約+12%）
- トップに「営業時間・定休日・予約不可＋電話・お店の場所」を集約し、スクロールせずに用が足りる形に
- 料理写真を看板の実物に差し替え、価格・表記も看板に合わせた
- 石臼（`stone-mill.jpg`）と手打ち（`craftsman-hands.jpg`）は不使用
- 素材差し替えが必要な箇所にHTMLコメントで `【素材待ち】` `【要確認】` を残してある

各パターンに `index.html`（トップ）／`menu.html`（お品書き）／`access.html`（アクセス・営業時間）／`style.css`。

## 全案に共通で実装した「参考サイトからの改良点」

3. PCでもグローバルナビを隠さない（ハンバーガーはスマホのみ）
4. お品書きは画像・PDFでなくHTMLテキスト＋税込価格
5. 全品掲載（「他にもございます」で終わらせない）
6. 電話は `tel:` でタップ発信、地図はGoogleマップ埋め込み＋経路リンク
7. スマホは画面下に「電話」「地図」を固定表示
8. 重いオープニング演出を入れない（LCP対策）

## WordPress 化の方針（D案で確定・素材が揃い次第着手）

- 固定ページ3枚（トップ／お品書き／アクセス）＋「お知らせ」を投稿タイプで運用
- お品書きは ACF（または再利用ブロック）で「品名・価格・注記・タグ」を配列管理し、店主が価格だけ直せる形に
- 営業時間・電話・住所はテーマオプション1箇所で管理し、全ページに出力（更新漏れを構造的に防ぐ）
- 「本日の営業／臨時休業」はお知らせ投稿の最新1件をトップに自動表示
